🔄 Linh Programming Language

Execution Flow Diagram - Kiến trúc và luồng thực thi

1
Input & Lexical Analysis
📁 Main.cpp
Entry point, handles command line arguments and file input
📝 Source Code
Linh source code (.li files) or REPL input
🔤 Lexer (Lexer.cpp)
Tokenizes source code into tokens (keywords, identifiers, literals, operators)
🏷️ Token Stream
Sequence of tokens with type, lexeme, literal value, line, and column information
2
Parsing & AST Generation
🌳 Parser (Parser.cpp)
Parses token stream into Abstract Syntax Tree (AST) using recursive descent
📊 AST Nodes
Expression, statement, and declaration nodes representing program structure
🔍 Semantic Analyzer
Type checking, scope analysis, and semantic validation
✅ Validated AST
Semantically correct AST ready for code generation
3
Bytecode Generation
⚡ BytecodeEmitter
Traverses AST and generates bytecode instructions
📦 BytecodeChunk
Sequence of instructions, constants, and metadata
🔧 Function Table
Mapping of function names to their bytecode and parameters
📋 Import Resolution
Handles package imports and merges function tables
4
Virtual Machine Execution
🖥️ LiVM (Virtual Machine)
Executes bytecode instructions with stack-based architecture
📚 Value System
Handles int, uint, float, bool, string, array, map, function, and sol types
🔄 Call Stack
Manages function calls, local variables, and return addresses
🎯 Instruction Execution
Executes arithmetic, control flow, function calls, and I/O operations
5
Runtime & Output
📤 I/O Operations
Print statements, input handling, and console output
🧮 Math Operations
Built-in mathematical functions and operations
🔄 Loop Control
While, do-while, for loops with break/continue
🎭 Error Handling
Try-catch blocks and exception management
6
Package Management
📦 LiPM (Package Manager)
Manages package imports and dependencies
📁 Package Directory
Stores built-in packages (math, time, etc.)
🔗 Import Resolution
Resolves package imports and merges functions
⚙️ Built-in Functions
Provides standard library functions

🚀 Optimization Features

Constant Folding
Evaluates constant expressions at compile time
Dead Code Elimination
Removes unreachable code during compilation
Instruction Caching
Caches frequently executed instructions for faster execution
Stack Optimization
Optimizes stack operations and memory usage
Hot Path Optimization
Identifies and optimizes frequently executed code paths

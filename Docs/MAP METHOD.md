| Method         | Ý nghĩa/Tác dụng                                              | Ghi chú                                         |
|:--------------|:-------------------------------------------------------------|:------------------------------------------------|
| .delete(key)  | Xóa phần tử có key là key khỏi map                           | Nếu không có key thì không thay đổi             |
| .clear()      | Xóa toàn bộ các phần tử trong map                            | Làm map thành rỗng                              |
| .keys()       | Trả về danh sách các key của map                             | Trả về array                                    |
| .values()     | Trả về danh sách các value của map                           | Trả về array                                    |
| m[key]        | Lấy giá trị theo key                                         | Truy cập key                                    |
| m[key] = x    | Gán giá trị x cho key                                        |                                                  |
| len(m)        | Trả về số lượng phần tử trong map m                          | Hàm toàn cục, dùng cho array/map/string         |
